# v2 改动说明

目标：按用户反馈「太多没用的小文字」，做一个更简洁、动效更好的画面。v1 保留在 ../v1，未改动。

## 删掉了什么
- 顶栏整条：「个人工作台」、「交互预览 · 示例资料」徽标、头像、说明按钮。
- 侧栏：「我的资料 / 个人与项目」、「资料分类」小标题、每类的数量、「预览说明与参考」、「本地优先 · 草稿仅存此浏览器」。
- 页面：分类副标题（如「挑选这次任务需要的技能。」）、「已确认常用 / 其他技能」分组标题与说明、「全部 / 常用 / 已加入」筛选条、结果数量「8 个技能」、网格 / 列表切换、底部「只交接你选中的资料 · 示例清单 · 不操作源文件」。
- 卡片：「常用 / 个人资料」状态字、标签行、来源文字行、「N 个文件」、两行描述（改为一行短用途）、「加入」文字按钮（改为圆形 + / ✓）。
- 购物车：「为下一位 Agent 准备资料」、分组小标题、每条「Codex · 3 个文件」、「已选 3 项 · 5 个文件 / 3 类资料」、「预览草稿保存在此浏览器」、空状态的三行说明。
- 交接预览：「内容预览 · 示例资料……」提示条、每条的状态文字、底部说明段落。
- 「预览说明与参考」整个抽屉。

## 新增 / 改成了什么
- 左侧悬浮图标导航：5 个分类只显示图标，悬停出现 Tooltip；当前分类由一块墨色指示器弹簧滑动过去。
- 大标题 + 浅色数量；右上只保留搜索框和来源分段控件（全部 / Codex / Claude Code / Cursor 四个小图标）。
- 卡片只留：图标块、名称、一行用途、来源小图标（悬停显示名称）、圆形加入按钮。缺少文件 / 已过期只用一个琥珀色小点，悬停显示。
- 右侧细长购物车：已加入的条目以小图标逐个堆叠，下方一个「→」直达交接预览；点购物车图标展开成完整面板（任务说明、条目列表、清空、预览交接）。
- 交接预览改为居中 Dialog：任务 / 项目位置可编辑，已选条目以胶囊显示且可移除；先点「生成提示词」，生成后显示「提示词已生成」，再「复制提示词」。
- 「示例」只在一处出现：导航底部的「示例」小标签（悬停说明全部为示例数据）；提示词正文首行仍声明「界面预览示例，尚未生成真实交接包」。
- 窄屏：顶部分类条（只有当前分类显示文字）、单列卡片、底部悬浮购物车胶囊，打开 Astryx Drawer。
- 左下角新增「减少动态效果」开关（系统已开启时自动锁定）。

## 动效清单
1. 弹簧曲线：src/motion.js 用阻尼弹簧模拟生成 CSS `linear()`，四档（snappy / bouncy / soft / gentle）。
2. 卡片悬停：上浮 5px + 跟随指针的 3D 轻微倾斜 + 指针位置的柔光；图标块轻微旋转放大。按下回弹缩小。
3. 加入：
   - 状态与计数立即更新，不等动画；
   - 卡片图标的副本沿弧线飞向购物车（起飞时放大、途中旋转、落地缩小淡出），后跟两颗彗尾光点；
   - 按钮 + 旋转消失、✓ 描边画出，周围 8 颗粒子迸开；
   - 落地时购物车图标弹一下并扩散一圈光环；数字向上滚动；新条目在副本落地时才从顶部弹入堆叠。
4. 移除：副本从购物车堆叠飞回卡片，卡片图标落地时弹一下；堆叠 / 列表中的条目缩小折叠离场；数字向下滚动；提示条可撤回。
5. 连点：同一条目 320ms 内的重复点击被忽略；状态用 Set 保存，不会重复加入。飞行中反向操作会从副本当前位置接续。窗口尺寸变化、开启减少动态效果时取消装饰动画。
6. 切换分类：导航指示器弹簧滑动；标题按方向带模糊滑入；旧网格快速淡出，新卡片按序错落升起（每张间隔 42ms）。
7. 来源筛选：白色滑块在分段控件中弹簧移动。
8. 购物车展开：宽度弹簧展开，细长视图淡出、完整面板稍后淡入，背景出现轻微模糊。
9. 详情抽屉：Drawer 内容逐行错落进入，图标块弹入。
10. 交接预览：对话框从下方缩放进入，胶囊依次弹出；「生成提示词」时图标旋转、面板扫光，完成后「提示词已生成」徽标弹出，提示词逐行模糊淡入。
11. 复制：按钮变色并回弹，✓ 描边画出，12 颗粒子迸开，提示词框描边亮起并扫过一道光。
12. 提示条、空状态的呼吸占位、空购物车图标轻微呼吸。
13. 减少动态效果（系统设置或开关）：不飞行、不倾斜、不出粒子，动画和过渡缩短到 1ms；仍然更新选中状态和数量，并在加入 / 移出时显示简短提示条（可撤回），符合 ux-spec.md 第 5 节。

## 保留的功能行为
- 查看详情（点卡片）与加入（点圆形按钮）分开。
- 跨分类保留选择；选择、任务说明、项目位置保存在本浏览器（键 `skillbridge.cart-preview.v2`，与 v1 分开）。
- 空购物车：「→」、「预览交接」、「生成提示词」都不可用，不会生成提示词。
- 「生成交接包」保持禁用（悬停显示「尚未接入」）；复制只表示剪贴板完成。
- 清空可撤回。

## 已检查
- `npm run build` 通过（Vite 对 Astryx 的 "use client" 指令和包体积有警告，不影响运行；v1 同样存在）。
- 在 box 上用无头 Chromium（Playwright）运行 1440×900、1024×768、390×844（触屏模拟）和减少动态效果模式：页面渲染正常、控制台无报错；加入 / 移除 / 跨分类计数、清空与撤回、刷新后恢复、空购物车按钮禁用、复制到剪贴板都按预期；390px 无横向溢出。

## 未验证
- 无头浏览器检查不等于真机测试：动画的流畅度、帧率、触屏手感、Windows 字体（Segoe UI / 微软雅黑）下的排版都没在真实设备上看过。
- Safari / Firefox 未测试；`linear()` 缓动在旧浏览器会回退为 cubic-bezier，弹性感会变弱。
- 屏幕阅读器只做了基础标注（aria-label、role、live region），未用真实读屏软件走查。
- 来源图标是自绘示意，不是 Codex / Claude Code / Cursor 的官方标志。
- 未截图、未录屏（按用户要求跳过）。
