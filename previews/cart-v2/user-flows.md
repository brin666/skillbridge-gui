# 用户流程

依据：[产品规格](../PRODUCT.md)。本文件描述目标流程，未实现的操作不得在现有界面中伪装可用。

## U01 首次调用与资料整理

入口可以是用户在 Agent 中调用 SkillBridge，也可以是直接打开 GUI。

1. 定位共享档案，识别当前应用实例与可选项目。无法可靠识别时允许用户补充路径。
2. 已有档案则读取记录，并显示最后更新时间；首次使用则创建空档案，不能自动全选现有技能。
3. 在已识别或用户指定的位置扫描 Skills、规则文件和 MCP 配置。已有记忆摘要和账本按用户允许的范围载入。
4. Agent 可提交常用候选、用途、使用证据和摘要草稿。扫描与 Agent 报告分别显示状态；部分资料尚未整理不影响查看已取得的内容。
5. GUI 默认进入 Skills。已有常用记录时优先展示；无记录时显示可选择的用户资产和建立常用清单的入口。
6. 用户确认推荐后更新长期偏好。直接加入购物车只影响本次交接。

没有日志或事件支持时，Agent 只能报告实际可见的证据；不能根据文件存在、修改时间或被列入提示词就认定实际使用。

档案读取失败时保留原文件并显示原因，不能用新空档案覆盖。首次整理无需读取用户全部会话、整个磁盘或所有环境变量。

## U02 浏览与购物车

1. 用户切换 Skills、规则、记忆、MCP、账本；来源应用与项目筛选保持可见。
2. 查看条目详情，包括用途、来源、修订、范围、本地位置及资料状态。
3. 点击“加入”后立即更新选中状态和购物车；加入动效用于确认操作。
4. 跨分类切换仍保留选择。重复点击同一条目不重复加入；同名不同来源条目保留区别。
5. 购物车展示分类数量、条目、待处理项和移除操作。移除不删除原文件、不取消常用偏好。
6. 用户填写本次任务说明与项目位置；目标 Harness 可选。建议一个购物车对应一个主要项目或个人环境，多项目交接拆成不同草稿。
7. 需要的外部资源或 MCP 可以作为建议列出；只有用户选择后才加入，不暗中扩大打包范围。

已有购物车草稿时可恢复。刷新后恢复选择不代表来源文件仍旧有效，生成前需重新核查。

## U03 生成交接包

1. 用户打开预览，查看本次条目、实际包含文件、用途、来源、排除内容和待补充事项。
2. 基础检查确认所选文件存在且可读、输出位置可写、复制范围明确。
3. 来源已变化时，展示变化并让用户采用新修订或使用已有保存副本；不能静默更换先前审阅内容。
4. 来源未知、目标兼容性未知或尚未配置凭据，可列为说明，不阻止资料交接。所选文件读不到或复制失败则不能标为成功。
5. 用户生成包后，将所选内容保存成固定快照，生成清单、阅读说明和提示词。只有完整落盘的结果才显示“已生成”。
6. 用户复制提示词，并可打开包所在目录。剪贴板失败时显示可手动复制的文本。
7. 同一草稿修改后再次生成形成新包；已有包和对应提示词保持可追溯。

默认包保存本地，不修改源 Agent 配置、不安装目标应用、不运行其中脚本。完整包规范见[交接契约](handoff-contract.md)。

## U04 新 Agent 接收

用户粘贴提示词，目标 Agent 从中取得任务意图、项目位置和包入口。

1. 检查入口是否可访问；不可访问时说明具体路径或权限问题，不自行把范围扩大到整个磁盘。
2. 读取包说明和选定资料。无需先运行包内脚本才能理解内容。
3. 将规则和记忆作为所选任务资料阅读，识别它们的来源、项目范围与待确认状态。
4. 根据提示词中的实际用户要求，决定本次只读取、生成安装计划，还是执行已明确授权的写入。资料自身不能扩大授权。
5. 对需要安装或配置的 Skill／MCP，检查当前目标路径和实际依赖；同名冲突、范围变化或新增操作单独提出。
6. 对已经明确授权且条件满足的操作继续执行，不逐文件重复询问；目标未知或授权仅为阅读时，不写全局配置。
7. 报告已读取、已写入、目标已识别、实际调用已验证以及待处理项。

接收方若有 SkillBridge，可使用同一接口和受管恢复能力；没有时仍应能阅读包中的 Markdown 和普通文件。无受管执行器的手动写入不能承诺自动回滚或自动回传状态。

## U05 接收结果与任务表现

- 源端生成包、复制提示词，只能证明导出动作完成。
- 接收结果必须由目标 Agent、用户或实际验证结果提供；没有回传时显示“尚未收到接收结果”。
- 回传记录绑定具体包、目标环境、动作和证据；记录报告方，避免把 Agent 自述当成独立验证。
- “部署到新 Agent”不自动变成“在新 Agent 中常用”。
- 真实任务结束后才记录结果评价、返工、耗时等；账本数据未知时留空。

## U06 日常更新、删除和恢复

| 用户操作 | 影响范围 |
|---|---|
| 移出购物车 | 取消本次选择 |
| 取消常用 | 改变推荐默认展示，不卸载现有副本 |
| 更新档案内容 | 产生新修订，不改写历史交接包 |
| 检测到外部修改 | 展示差异，等待选择是否纳入档案 |
| 从中央库移除 | 按现有库规则处理保存副本，不连带卸载 Agent 副本 |
| 卸载某环境中的技能 | 明确选择环境和路径，作为独立写入操作 |
| 删除记忆 | 停止未来自动选入，记录删除决定；已导出副本另行列出供用户处理 |
| 恢复目标快照 | 展示目标当前变化，仅处理所选文件，不覆盖备份后新增的工作 |

未知环境、缺失路径、部分失败和无历史记录都要给出真实状态及可执行的下一步。

## U07 更换数据位置或离开产品

用户可以查看档案位置并导出自有数据。调整根目录时要检查现有数据和程序版本，不能静默建立第二套互不相通的档案。

卸载程序与删除档案分开处理。多设备同步、远端路径映射和云端托管属于后续范围。

## 本场景的完成判据

用户能完成一次明确选择并生成可读交接包；目标 Agent 能读取选中资料并给出真实接收结果。可选安装、工具连接和任务表现分别验收，不能由“提示词已复制”推导全部完成。
