# 资料购物车预览 · 方案 01

状态：独立、可操作的设计预览，待用户评审；不代表正式 GUI 已获批准。

## 任务与结构

Operate 模式。用户在自己的电脑上为下一项 Agent 任务收集资料；浅色工作区使正文、来源与选择状态便于连续阅读。

- 桌面：72px 顶栏；216px 分类导航；中间两列资料卡片；340px 常驻购物车。
- 1100px 及以下：购物车收起为固定底部入口，以 Astryx Drawer 打开。
- 720px 及以下：一行五种分类，资料卡片单列；底部购物车始终可达。
- 默认 Skills；规则、记忆、MCP、账本使用相同的浏览与选择语言。
- 常用只影响展示顺序，不预先选中条目；同一条目只出现一次。

## Astryx 的复用与本次设计

使用已发布的 `@astryxdesign/core@0.7.13`、`@astryxdesign/theme-neutral@0.7.13`，在独立 React 19 预览中运行。

| 依据 | 复用位置 |
|---|---|
| Astryx Neutral | 基础控件、留白、分隔与焦点样式 |
| Astryx Card Grid 模板 | 搜索、分类筛选、离散资料卡片 |
| SideNav / SideNavItem | 五类资料的导航与计数 |
| TextInput / Button / Card | 搜索、任务说明、加入动作与资料展示 |
| Drawer | 资料详情、窄屏购物车、交接内容预览 |
| 项目 docs/ux-spec.md | 购物车状态、完整资料范围、来源与结果表达 |

常驻购物车、分组条目、飞入与撤回动效由本预览设计。源文件读取、生成包和实际接收流程尚未接入。

## 视觉规则

- 背景 `#FFFFFF`，导航 `#F8F9FC`，购物车 `#FAFBFE`。
- 正文 `#202536`；主操作 `#4057D8`；选中底色 `#EEF1FF`。
- 通用辅助文字使用 `#647087`；对比度为白底 4.99:1、购物车底色 4.82:1。
- 界面沿用系统字体栈，中文优先 PingFang SC / Microsoft YaHei；路径使用等宽字体。
- 页面标题 30px，卡片标题 16px，主体说明 12–13px；窄屏说明 13px。
- 卡片圆角 13px，按钮和输入框 8px；容器使用细边框，不叠加大阴影。
- 色彩小面积区分资料图标；选中状态同时使用文字、勾选图标和边框，避免仅靠颜色。
- 列表视图在资料文案中直接标出「缺少文件」或「已过期」，保持状态可见。

## 交互与状态

- 加入立即更新集合、计数和按钮；用独立的文字标记从触发处飞至购物车入口。
- 飞行时长 480ms，`cubic-bezier(.2,.7,.25,1)`；中段抬起 45px，末端缩小淡出。原卡片保持可操作。
- 重复点击为移出／重新加入；逆向操作从当前飞行位置接续。分类切换、尺寸变化取消装饰动画，不改变选择。
- 系统或预览设置开启减少动态效果时，跳过飞行；仍更新状态和提示。
- 详情与加入分开；Drawer 负责模态焦点、Esc 关闭和焦点返回。
- 窄屏购物车 Drawer 标题行提供清空与关闭操作。
- 空列表、空购物车、示例缺失文件、过期记忆、凭据待补充分别展示。
- 预览草稿仅使用 `skillbridge.cart-preview.v1` 浏览器存储键；存储失败时明确提示。
- 「生成交接包」保持禁用；可复制的示例提示词声明没有实际文件包。
