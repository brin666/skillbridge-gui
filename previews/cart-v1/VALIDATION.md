# 预览验证记录

日期：2026-11-11。范围仅为 `previews/cart-v1`，不代表正式产品功能验收。

## 构建与依赖

- `npm.cmd run build` 通过。
- 使用已发布 Astryx Core / Neutral 0.7.13 与独立 React 19.2.0。
- 打包保留 index.html 中的方向契约。
- 机械 UI 检查执行一次，返回 `[]`。
- Vite 报告第三方 `use client` 指令在纯客户端打包中被忽略，以及单个 JS chunk 大于 500kB。本地预览正常运行；正式集成前需要按实际使用拆分与评估体积。

## 实际操作检查

| 场景 | 结果 |
|---|---|
| 连续加入 Skills，再进入规则、记忆选择 | 四个条目跨分类保留，分组和总数一致 |
| MCP 加入后移出，账本加入后从购物车移除 | 集合恢复正确，没有数量累计 |
| 打开技能详情 | 不改变选择 |
| 详情焦点、Shift+Tab、Escape | 焦点保持在 Drawer，关闭后返回触发按钮 |
| 搜索不存在的名称 | 展示空状态，查看全部可以恢复 |
| 来源筛选 Cursor | 仅展示对应的两条示例技能 |
| 选择缺少脚本的示例 | 交接预览明确指出 scripts/timeline.js 缺失 |
| 刷新页面 | 独立预览草稿恢复四条选择 |
| 启用减少动态效果 | 加入立即生效，飞行元素数量为零 |
| 同一事件批次快速加入两项、撤回其中一项 | 购物车五条且五个不同 ID，动画结束后无残留标记 |
| 列表／卡片切换 | 显示模式改变，选择保持 |
| 412px 窄屏导航 | 五分类单行，导航高度约 57px，无页面水平溢出 |
| 窄屏购物车 Drawer | 可打开，宽 356px，焦点进入 Drawer，能移除条目 |
| 窄屏切到规则 | 剩余三条选择保留，无水平溢出 |
| 生成交接包按钮 | Astryx `aria-disabled=true`，未绑定导出行为 |

桌面交互使用 ego-browser 的页面操作。窄屏布局使用浏览器视口模拟；窄屏点击使用页面 DOM 触发，因为工具的原生鼠标操作会恢复桌面视口。没有进行真手机触控验证。
