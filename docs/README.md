## 文档使用规则

- 用户最新明确要求优先；产品范围以 PRODUCT.md 和 decisions.md 的“已确认”项为准。
- 流程、交互和契约描述目标行为，不代表当前代码已经支持。
- 标记为“建议”的存储、命令名称、阶段安排等可以在开发准备时调整，不能当作已获用户确认的 UI 或上线方案。
- 新版视觉、布局与“加入购物车”的动效须先提供参考和直观预览，经确认后实施。
- 本机档案、导出包和真实使用记录属于用户数据，不纳入源码仓库。
- 用户提供的外部产品草稿是参考资料，其中的市场数字、平台配置映射、定价和发布计划未在本轮核实或采用为开发承诺。
