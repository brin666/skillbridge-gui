# 验收清单

状态：后端已完成自动化验证；下列条目仍是完整产品验收，不等于 GUI 或真实 Harness 已通过。需求编号见 [PRODUCT.md](../PRODUCT.md)。

## 2026-11-11 后端验证范围

新增 tests/test_workspace.py 与 tests/test_workspace_transports.py 共 33 项测试，覆盖共享档案、推荐不自动确认、分范围常用、完整目录与五类资料导出、同名区分、并发选择、源变化、取消／中断、凭据处理、包损坏、报告去重、CLI 与 HTTP 共用数据。运行 python -B -m unittest discover -s tests -q，232 项通过（含原有 199 项）。旧测试仍有 HTTPError 资源清理警告，结果为 OK。

新增 Python 文件语法、metadata.json 和文档相对链接也已核对；未改前端，因此本轮未运行前端构建或浏览器测试。

测试使用临时目录和合成资料，未向真实 Agent 配置写入，也未做真实 MCP 连接。新 GUI、剪贴板交互、真实目标识别、受管写入与恢复、任务指标和跨版本迁移仍需对应阶段验证。返回 runtimeVerified=false 的文件校验不能当作目标执行成功。

## 5. 证据要求

- 记录使用的样本、执行入口、源／目标环境与版本、实际结果和未覆盖内容。
- 导出完整性用文件清单和哈希核对；不能只凭界面弹出成功消息。
- Harness 识别或工具调用必须有实际目标证据；静态检查不能替代真实使用验证。
- 浏览器、无头测试、触控模拟和真实设备分别报告。
- 受控临时目录测试不代表已经在用户全部真实配置上验证，不因此自动执行真实迁移。
- 本轮文档验证只检查内容一致性、链接、模板和工作区改动范围，不将上述条目打勾。
